# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Annapurna, please report it responsibly. Do not disclose it publicly until it has been reviewed and addressed.

To report a vulnerability, please contact the maintainer directly via GitHub at [ShashankS1011](https://github.com/ShashankS1011). We will acknowledge receipt of your vulnerability report within 48 hours and provide regular updates as we investigate and fix the issue.
